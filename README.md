# buffer-reel-audio-swap

Public hosting for the royalty-free music versions of scheduled Buffer Reels (Instagram, TikTok, YouTube, and X for changealtitude).

The videos live as **GitHub Release assets** (not in git) so Buffer can download them from a direct public URL. One file is over GitHub's 100MB git limit, so release assets are the intended upload path.

Licenses and track credits are in [`tracks.md`](tracks.md). All tracks are CC0 1.0.

This repository is a temporary media host for the scheduled queue. Do not treat it as a portfolio or a source of original music.
